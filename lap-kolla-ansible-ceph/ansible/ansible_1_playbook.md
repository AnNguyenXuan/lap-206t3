### Thiết lập playbook cho Ansible
```
Tạo một playbook.yaml, cho vào đó nội dung sau :
- name: My first play
  hosts: myhosts
  tasks:
   - name: Ping my hosts
     ansible.builtin.ping:

   - name: Print message
     ansible.builtin.debug:
       msg: Hello world

Chạy playbook : ansible-playbook -i inventory.ini playbook.yaml
PLAY [My first play] **********************************************************************************************************************************************************************************************

TASK [Gathering Facts] ********************************************************************************************************************************************************************************************

TASK [Print message] **********************************************************************************************************************************************************************************************

    msg: Hello world

```
