# Giới thiệu

Odoo là một hệ thống ERP mã nguồn mở, được thiết kế cho doanh nghiệp nhỏ và vừa. Hệ thống bao gồm nhiều ứng dụng tích hợp như CRM, Sales, Inventory, HRM, Accounting và Project Management. Odoo được viết bằng Python và dễ dàng triển khai trên VPS bằng Docker hoặc cài đặt trực tiếp từ mã nguồn.

## Đặc điểm chính
- Mã nguồn mở, dễ tùy chỉnh theo nhu cầu.
- Có nhiều module miễn phí trong hệ sinh thái.
- Hỗ trợ các hoạt động quản trị doanh nghiệp: bán hàng, kế toán, kho, nhân sự.
- Giao diện web trực quan, thân thiện với người dùng.
- Dễ mở rộng bằng cách viết thêm module bằng Python.

## Lý do được tổ chức nhỏ ưa chuộng
- Chi phí triển khai thấp.
- Có thể tự host trên VPS để chủ động dữ liệu.
- Linh hoạt, phù hợp với nhiều quy mô và lĩnh vực.
